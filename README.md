### Requisitos adicionales

Este proyecto utiliza PySpark con soporte Hive embebido.  
Además de los paquetes listados en `requirements.txt`, es necesario tener instalado **Java 17** y definir la variable de entorno `JAVA_HOME`.

En entornos conda, se puede instalar fácilmente con:
```bash
conda install -c conda-forge openjdk=17
